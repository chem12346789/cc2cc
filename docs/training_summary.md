## Single-atom augmentation and weighting

`--append_mol0 N` adds N additional references to each one-atom dataset entry; including its original reference, each such system appears `N + 1` times. The same setting is used when constructing both train and evaluation datasets. `--mol0_weighting W` assigns each one-atom sample data weight W (multi-atom samples use their atom count); this weight is applied to the configured per-sample loss scales. Thus append count controls repetition, while weighting controls the contribution per occurrence. See [`BasicDataset`](../cc2cc/utils/DataBase.py#L28) and [per-sample data weighting](../cc2cc/utils/DataBase.py#L373).
